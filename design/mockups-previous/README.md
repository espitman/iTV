# طرح‌های نمایشی iTV

موکاپ ایستای HTML/CSS/JS برای ده صفحهٔ محصول. پیاده‌سازی اندروید نیست و به شبکه، CDN، یا تصویر راه دور وابسته نیست.

## اندازهٔ قاب

- همهٔ صفحات تلویزیون: **۱۹۲۰×۱۰۸۰** بدون اسکرول
- داشبورد وب: **۱۴۴۰×۹۰۰** بدون اسکرول

پس‌زمینهٔ سند جوهر تیره است. برای ثبت تصویر، خودِ قاب `.stage` را در مقیاس ۱:۱ بگیرید؛ اگر پنجره بزرگ‌تر باشد حاشیه دیده می‌شود.

## رندر محلی

از پوشهٔ `design/mockups` یک سرور ساده اجرا کنید تا فونت IR Terafik از مسیر نسبی بارگذاری شود. بعضی مرورگرها روی `file://` فونت محلی را مسدود می‌کنند.

```sh
cd design/mockups
python3 -m http.server 8765
```

بعد در مرورگر:

```
http://127.0.0.1:8765/index.html?screen=<name>
```

نمونهٔ ثبت با Chrome در اندازهٔ دقیق تلویزیون:

```sh
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless --disable-gpu \
  --window-size=1920,1080 \
  --screenshot="$PWD/home.png" \
  "http://127.0.0.1:8765/index.html?screen=home"
```

برای داشبورد همان دستور با `--window-size=1440,900` و `screen=web-dashboard`.

## صفحه‌ها

| `screen` | قاب | موضوع |
| --- | --- | --- |
| `home` | ۱۹۲۰×۱۰۸۰ | کتابخانه با ویژهٔ زیرخاکی، ادامه تماشا، تازه‌ترین‌ها |
| `series-single` | ۱۹۲۰×۱۰۸۰ | دیوار دفاعی، یک فصل، فوکوس قسمت ۲ |
| `series-multi` | ۱۹۲۰×۱۰۸۰ | زیرخاکی، چهار زبانهٔ فصل، فصل ۲ |
| `player-controls` | ۱۹۲۰×۱۰۸۰ | پخش دیوار دفاعی با نوار زمان و کنترل جهت‌نما |
| `player-resume` | ۱۹۲۰×۱۰۸۰ | ادامه / از ابتدا و شمارش ۵ ثانیه |
| `player-skip` | ۱۹۲۰×۱۰۸۰ | تراشهٔ رد کردن تیتراژ |
| `player-next` | ۱۹۲۰×۱۰۸۰ | کارت قسمت بعد در ۳۰ ثانیهٔ پایانی |
| `tv-settings` | ۱۹۲۰×۱۰۸۰ | جفت‌سازی، نشانی، رمز، وضعیت |
| `web-dashboard` | ۱۴۴۰×۹۰۰ | طرح پنل مدیریت با پیش‌نمایش دیوار دفاعی |
| `home-empty` | ۱۹۲۰×۱۰۸۰ | کتابخانهٔ خالی و راهنمای افزودن |

## فونت و تصویر

- IR Terafik از `../../app/src/main/res/font/irterafik.ttf` و `irterafikbold.ttf`
- پوستر و تصویر عریض فقط از `assets/` همین پوشه

## نقش ارتباطی

صفحهٔ تنظیمات یک QR واقعی نسخهٔ ۲ با تصحیح M برای نشانی `http://192.168.1.42:8191` می‌سازد. کد تولید در `qr.js` خودکفا است و به سرویس بیرونی وابسته نیست.

## یادداشت داشبورد

سربرگ داخل موکاپ فقط «iTV» و «کتابخانهٔ همین تلویزیون» است. نام «طرح پنل مدیریت» فقط برای همین سند است، نه متن روی صفحه. پنل مثل صفحهٔ سرو‌شده از تلویزیون طراحی شده و وضعیت زندهٔ سرور جعل نشده است.
